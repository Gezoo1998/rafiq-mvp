1 Push Code to GitHub / GitLab

The local git repository has all latest MVP features committed. Push it to a GitHub repository so Vercel can automatically build and deploy it. 

# 1. Create a new repository on GitHub (e.g., rafiq-mvp)
# 2. In your terminal at e:\rafiq mvp, link and push:
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/rafiq-mvp.git
git branch -M main
git push -u origin main
Note: Your .env file is listed in .gitignore and will never be pushed to GitHub. All secrets will be securely configured in Vercel's dashboard.
2 Set Up a Cloud PostgreSQL Database

Vercel serverless functions cannot connect to your local PC (localhost:5432). You need an online PostgreSQL database. We strongly recommend Neon Serverless Postgres (takes 60 seconds and has a generous free tier).

A

Neon.tech (Recommended)

Go to neon.tech, create a free project named rafiq-db.

Copy the connection string (Connection Details $\rightarrow$ Pooled connection or direct string):

postgresql://username:password@ep-xyz.us-east-2.aws.neon.tech/rafiq?sslmode=require
B

Alternative: Supabase or Railway

If using Supabase, go to Project Settings $\rightarrow$ Database $\rightarrow$ Connection string (NodeJS / Transaction pooler mode on port 6543 or 5432 with ?sslmode=require).

3 Apply Schema & Seed Demo School into Cloud Database

Before your app can log in on Vercel, the cloud database needs the 16 tables and initial demo users. You can run this once from your local computer: 

# In e:\rafiq mvp\.env temporarily set your cloud DATABASE_URL:
# DATABASE_URL=postgresql://username:password@ep-xyz.neon.tech/rafiq?sslmode=require

# Then push the Drizzle schema:
npm run db:push

# Then populate the demo school, teachers, students, and missions:
npm run seed
Important: Save the printed access codes from npm run seed! Those will be the codes you use to log in online.
4 Import Project in Vercel
  1. Log in to Vercel.com.
  2. Click "Add New..." $\rightarrow$ "Project".
  3. Import your GitHub repository rafiq-mvp.
  4. Keep Framework Preset as Next.js and Root Directory as ./.
  5. Expand the "Environment Variables" section (see table below).
  6. Click "Deploy".
5 Production Environment Variables

Configure these exact environment variables in your Vercel Project Settings (Settings $\rightarrow$ Environment Variables):

Variable Type Production Value / Description
DATABASE_URL REQUIRED Cloud PostgreSQL connection string with SSL.
postgresql://user:pass@ep-xyz.neon.tech/rafiq?sslmode=require
SESSION_SECRET REQUIRED Cryptographic key for signing user session JWTs (at least 32 characters).
Generate with: openssl rand -hex 32
CODE_PEPPER REQUIRED Pepper string for HMAC-SHA256 hashing of access codes before saving to DB.
Generate with: openssl rand -hex 32
SYSTEM_ADMIN_BOOTSTRAP_CODE REQUIRED A high-entropy secret code to bootstrap an admin via POST /api/auth/bootstrap if ever needed.
Example: rafiq-prod-bootstrap-key-9921
AI_PROVIDER REQUIRED openai_compatible (for Groq / Together / DeepSeek) or openai or mock.
AI_BASE_URL RECOMMENDED API endpoint for OpenAI-compatible provider.
For Groq: https://api.groq.com/openai/v1
AI_API_KEY REQUIRED Your API key (e.g. Groq gsk_... or OpenAI sk-...).
(Leave empty only if AI_PROVIDER=mock).
AI_MODEL_TUTOR RECOMMENDED Model for student tutoring chat.
For Groq: llama-3.3-70b-versatile
For OpenAI: gpt-4o-mini
AI_MODEL_EVAL RECOMMENDED Model for rubric evaluation & grading.
For Groq: llama-3.3-70b-versatile
For OpenAI: gpt-4o-mini
AI_SEND_STUDENT_NAME RECOMMENDED false (Enforces Section 10.1 strict privacy: student names are NEVER sent to the LLM).
AI_COST_PER_1M_INPUT_TOKENS_USD RECOMMENDED 0.59 (Used in System Admin usage billing calculation).
AI_COST_PER_1M_OUTPUT_TOKENS_USD RECOMMENDED 0.79 (Used in System Admin usage billing calculation).
APP_BASE_URL REQUIRED Your deployed production domain.
Example: https://rafiq-mvp.vercel.app
TZ RECOMMENDED Asia/Riyadh (For correct mission deadline and timestamp rendering).
